Fluxo comercial

Cadastre clientes e produtos, registre pedidos e acompanhe as vendas em um só lugar.

Cadastrar Cliente

Nesta etapa

Registre a base de clientes que vão aparecer nos pedidos.

  • Use um ID único para cada cliente
  • Depois cadastre os produtos
  • Os dados ficam salvos neste navegador

Cadastrar Produto

Nesta etapa

Monte o catálogo com nome e preço para calcular o valor dos pedidos.

  • Informe o preço em número
  • O ID do produto será usado no pedido
  • Em seguida, registre a venda

Cadastrar Pedido

Nesta etapa

Una cliente e produto para gerar o pedido e o valor total.

  • Escolha um cliente já cadastrado
  • Informe o ID do produto
  • A lista de vendas mostra o resultado
